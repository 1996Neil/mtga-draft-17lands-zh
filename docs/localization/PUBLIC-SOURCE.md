# 公开源码边界

代码沿用上游 MIT 许可证并保留原版权声明；数据权利见根目录 `DATA-NOTICE.md`。
这不是官方游戏、17Lands 或上游作者的官方中文发行版。

公开内容包括源代码、通用文档、合成测试、去除游戏正文的统计 fixture、
公开 names-only 基线、版本清单与原生窗口测试工具。

不公开：完整英文本地化表、游戏数据库、个人配置/日志/牌池、私有维护器资料、
本机路径或内部构建验收记录。旧的本机资料可在用户自己的目录保留，但不能被
版本控制或打包规则再次带入发布内容。

英文兼容使用用户本人原始数据库生成的最小身份索引，不从已汉化内容“猜回”英文。
相同版本复用索引；游戏版本变化才重新准备。公开构建不附带该本地索引。

公开前会清理所有远端分支中的排除路径、历史私人路径和历史 fixture 正文。
仅删除当前文件不能代表历史已清理；仍需扫描可达对象及托管平台历史制品。
历史重写会改变提交编号，旧工作副本不能把旧分支再次推回公开仓库。

公开后的克隆及后续提交统一使用整理后的历史。本地应用、用户配置和实际轮抽数据
独立于源码，不因历史清理而重置。
