# 中文启动差量更新契约

目标：打开应用即可检查中文版本，只有新变化才联网下载并应用；不影响轮抽。
范围：轮抽应用、公开 names-only 源的差量发布脚本和工作流。
不做：全量自动下载、常驻轮询、自动重试、依赖升级、评分计算变化、游戏文件修改。

## 启动成本

- 一次本地版本元数据查询和一次公开小清单请求；当前清单正文 64 字节。
- 同版本不读取内置全量 JSON、不验证存量行、不额外重建显示索引。
- 一个短生命周期后台线程。完成后退出，无新定时器、轮询或依赖。
- 本地基线只在首次初始化或应用内置版本升级时验证一次。
- 配置关闭联网仍可使用已有本地牌名；自定义源优先，不被自动源覆盖。

正常启动原有的当前牌池显示匹配仍然存在；这里的“无全量校验”指更新器不重复
校验全部已安装牌名，不是停止当前牌包的身份匹配和中文显示。

## 协议与失败边界

固定 HTTPS 公共源 `1996Neil/mtga-card-names/main/updates`，不携带用户凭据或游戏数据。
`latest.json` 最大 32 KiB；严格数值版本只前进，不回退。
链最多 64 步、压缩总量最多 4 MiB。单差量最多压缩 2 MiB、展开 16 MiB。
资源路径只能是 `patches/<sha256>.json.gz`；只允许牌名和对应身份字段。

只对新下载差量校验 SHA-256、版本、字段、变化数量与身份。通过主键读写变化行，
不扫描未变化的行；整链在一个事务中提交，任何一步失败均回滚。
HTTP 使用短超时与流式读取预算；系统 DNS/连接阶段不保证固定秒数的硬截止。
离线、超时、差量缺失、坏包、旧远端清单均保留现有可用牌名，没有整包下载后门。

SHA-256 防止传输/资产损坏，不是独立发布签名。发布者通过固定 GitHub HTTPS 源受信。
源端只接受已发布的稳定 `data-*` 版本；旧 release 不重写，差量按内容哈希命名。
发布工作流只进行普通快进提交，不强推。长时间未更新且缺少保留链时需应用新基线。

## 验证入口

```sh
python -m pytest tests/test_names_update.py tests/test_card_names_release.py \
  tests/test_chinese_display.py tests/test_app_controller.py -q
```

中文源：

```sh
python3 -m unittest discover -s tests -v
```

覆盖：同版本零行校验/一个版本请求，单行变更仅一次行校验，重试只查版本；
新增、修正、删除、跨版本链；整链坏包回滚、并发启动单飞与读写一致性；
离线无重试、无差量不回退全包、路径/尺寸限制、字段兼容；
关闭联网不回退内置旧版本、同版本不重建显示索引；
源端拒绝不兼容/超量行、预发布和草稿，变更包不含未变化行。
